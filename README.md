## О проекте

ShoeStore — настольное приложение для автоматизации работы магазина обуви.

Программа предназначена для управления ассортиментом товаров, просмотра заказов и выполнения основных операций с данными магазина. Доступные функции зависят от роли пользователя.

## Используемые технологии

| Технология | Назначение |
|---|---|
| C# | Основной язык программирования |
| WPF | Разработка интерфейса |
| .NET Framework 4.8 | Платформа приложения |
| Entity Framework 5 | Работа с базой данных |
| ADO.NET EDM | Модель данных |
| SQL Server | Хранение данных |
| Visual Studio | Среда разработки |

## Основные возможности

### Авторизация
- Вход по логину и паролю.
- Возможность входа в качестве гостя.
- Разделение прав доступа по ролям.

### Работа с товарами
- Просмотр списка товаров.
- Поиск по различным параметрам.
- Фильтрация по поставщикам.
- Сортировка по количеству на складе.
- Добавление, редактирование и удаление товаров.
- Загрузка и отображение фотографий.
- Отображение скидок и итоговой стоимости.
- Выделение товаров в зависимости от размера скидки и наличия на складе.

### Работа с заказами
- Просмотр списка заказов.
- Добавление новых заказов.
- Редактирование существующих заказов.
- Удаление заказов.
- Выбор товара и статуса заказа.
- Выбор пункта выдачи.
- Указание даты заказа и даты выдачи.
- Обновление списка после изменения данных.

## База данных

Для хранения информации используется SQL Server. Подключение и взаимодействие с базой данных реализовано с помощью Entity Framework.

Основные таблицы:

- `Products` — товары.
- `Users` — пользователи.
- `order` — заказы.
- `orderlist` — состав заказов.
- `status` — статусы заказов.
- `PickupPoints` — пункты выдачи.

## Установка и запуск

1. Склонировать репозиторий:

```bash
git clone <ссылка-на-репозиторий>
```

2. Открыть файл решения `.sln` в Visual Studio.
3. Убедиться, что установлен .NET Framework 4.8.
4. Подключить SQL Server и подготовить базу данных.
5. Проверить строку подключения в `App.config`.
6. Восстановить необходимые NuGet-пакеты.
7. Собрать решение и запустить приложение.
